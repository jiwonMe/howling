# E2E

제품 origin에서 로그인부터 HA helper까지를 Playwright가 돕니다. 호스트 머신에 테스트 CA를 설치하지 않습니다. Playwright `ignoreHTTPSErrors`는 금지입니다.

## Origin

| 이름 | 역할 |
| --- | --- |
| `https://howling.test` | web 정적 + `/api` `/health` `/ready` `/api/v1/runtime/ws` |
| `https://auth.howling.test` | 테스트 OIDC |
| `home-assistant` (compose DNS) | runtime → HA. 브라우저는 직접 가지 않음 |

개발 `pnpm dev`는 이 origin을 쓰지 않습니다.

## 한 줄

```bash
pnpm test:e2e
```

[`scripts/test-e2e.mjs`](../../scripts/test-e2e.mjs)가 하는 일:

1. `@howling/oidc-test` 빌드
2. `infra/tls/generated/howling.test.crt`가 없으면 `node infra/tls/generate.mjs`
3. `docker compose -f infra/compose/compose.yaml` 가 아니라 `infra/compose/compose.e2e.yaml`을 `down -v`
4. `up --build --abort-on-container-exit --exit-code-from playwright`
5. 끝나면 다시 `down -v`

개인키는 `infra/tls/generated/`에 있고 gitignore입니다. E2E 컨테이너에만 복사합니다.

## 스택

[`infra/compose/compose.e2e.yaml`](../../infra/compose/compose.e2e.yaml):

- postgres, oidc, api, web, runtime
- Home Assistant `ghcr.io/home-assistant/home-assistant:2025.8.3`
- `ha-control` — 공식 onboarding API로 owner를 만들고 LLAT를 `/secrets`에만 씀
- Caddy `tls-gateway` — `howling.test`, `auth.howling.test`
- Playwright — Dockerfile에서만 `update-ca-certificates`와 NSS

HA helper는 [`infra/e2e/ha/configuration.yaml`](../../infra/e2e/ha/configuration.yaml)의 `input_number.test_power`, `input_boolean.test_alert`입니다. `.storage` 조작이나 인증 해제로 통과시키지 않습니다.

E2E API는 `BOOTSTRAP_RUNTIME_TOKEN=""`입니다. Playwright는 pairing만 씁니다.

## 인증서와 브라우저

Chromium은 `NODE_EXTRA_CA_CERTS`를 쓰지 않습니다. Playwright 이미지 entrypoint가 CA를 시스템 store와 NSS DB에 넣습니다. `playwright.config.ts`는 `ignoreHTTPSErrors: false`입니다.

인증서를 다시 만들 때:

```bash
node infra/tls/generate.mjs
```

호스트 trust store는 그대로 둡니다.

## 전력 평균 시나리오

[`e2e/tests/power-alert.spec.ts`](../../e2e/tests/power-alert.spec.ts):

1. `owner@howling.test` / `howling-dev`로 로그인
2. `POST http://runtime:4000/v1/setup/pair` 후 `/connections`에 code 입력
3. `runtime-online` = `online`, `ha-status` = `ready`
4. 캔버스에서 평균 플로 작성·저장·검증·배포
5. 헤더가 `배포 active`
6. `ha-control` `/set-power`로 800, 900, 1100, 1200, 1400
7. 각 값마다 해당 flow의 run이 `completed`
8. `/runtime-hooks`의 `haServiceCalls === 1`, alert `on`
9. `/runs/:runId`에 같은 `runId`·revision

로그인만 보는 smoke는 [`e2e/tests/login.smoke.spec.ts`](../../e2e/tests/login.smoke.spec.ts)입니다.

Dry-run은 [`e2e/tests/dry-run.spec.ts`](../../e2e/tests/dry-run.spec.ts)입니다. 같은 평균 플로를 시험해도 `haServiceCalls`는 늘지 않고 `input_boolean.test_alert`는 `off`입니다. WSS 단절 뒤에도 live coordinator는 로컬에서 이어가고, 재연결 시 `summary.batch` 미ACK를 다시 올립니다. cursor 보충은 API journal 테스트로 확인합니다.

MCP는 [`e2e/tests/mcp.spec.ts`](../../e2e/tests/mcp.spec.ts)입니다. 테스트 MCP echo tool을 배포해 호출 1을 확인하고, 같은 플로 dry-run은 호출을 늘리지 않습니다.

관측은 [`e2e/tests/analytics.spec.ts`](../../e2e/tests/analytics.spec.ts)입니다. `/analytics` 네 위젯과 원본 ON·OAuth 제공자 목록을 확인합니다.

## 스택만 띄우고 로그 보기

`pnpm test:e2e`는 끝나면 volume을 지웁니다. 실패를 남기려면:

```bash
pnpm --filter @howling/oidc-test build
test -f infra/tls/generated/howling.test.crt || node infra/tls/generate.mjs
docker compose -f infra/compose/compose.e2e.yaml up -d --build
docker compose -f infra/compose/compose.e2e.yaml ps
docker compose -f infra/compose/compose.e2e.yaml run --rm --no-deps playwright
```

HA 제어 (토큰은 출력하지 말 것):

```bash
docker exec howling-e2e-ha-control-1 \
  node -e 'fetch("http://127.0.0.1:8090/ready").then((r)=>r.json()).then(console.log)'

docker exec howling-e2e-ha-control-1 \
  node -e 'fetch("http://127.0.0.1:8090/alert").then((r)=>r.json()).then(console.log)'
```

power 값 넣기:

```bash
docker exec howling-e2e-ha-control-1 node -e '
fetch("http://127.0.0.1:8090/set-power", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ value: 1400 }),
}).then((r) => r.json()).then(console.log)
'
```

정리:

```bash
docker compose -f infra/compose/compose.e2e.yaml down -v --remove-orphans
```

## 통과 기준

- `pnpm test` — core 40개 변경 없음
- `pnpm typecheck`, `pnpm build`
- `pnpm test:e2e` — 로그인 + 평균 플로 + helper 1회 + dry-run HA 0 + MCP echo 1 / dry-run 0 + `/analytics` 위젯

시드 `apps/runtime/fixtures/power-alert.json`만 배포해서 E2E를 통과시키지 않습니다.
